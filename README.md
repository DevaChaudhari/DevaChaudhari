## Featured Projects

**[AustraliaJobSeeker-AI](https://github.com/DevaChaudhari/AustraliaJobSeeker-AI)** — End-to-end AI agent job platform. Seek.com has no visa filter for international students, so this LangGraph multi-agent pipeline scrapes live jobs, filters by visa type (500/485/482/PR), ranks by resume match, and auto-generates tailored resumes and cover letters. Custom MCP servers expose tools; A2A servers enable multi-agent collaboration. Deployed on Google Cloud Run with Docker, Kubernetes, and CI/CD via Cloud Build.
`Python` `LangGraph` `LangSmith` `Groq` `FastAPI` `MCP` `A2A` `Docker` `Kubernetes`

**[ProjectPilot-AI](https://github.com/DevaChaudhari/ProjectPilot-AI)** — Autonomous multi-agent system with dedicated planner, executor, and tool-selection agents for dynamic task planning and multi-step LLM reasoning. Integrates 6+ external APIs for fully automated workflows, running on local LLM inference via Ollama.
`Python` `LangGraph` `LangChain` `FastAPI` `Streamlit` `Ollama`

**[YouTube-RAG-Chatbot](https://github.com/DevaChaudhari/YouTube-RAG-Chatbot)** — End-to-end RAG chatbot for querying YouTube video content in natural language. A four-stage pipeline achieves sub-second retrieval across 100K+ token transcripts. Dockerized with Kubernetes manifests.
`Python` `LangChain` `Gemini` `FAISS` `Docker` `Kubernetes`

**[A2A-Protocol-Implementation](https://github.com/DevaChaudhari/A2A-Protocol-Implementation)** — Minimal Python A2A-SDK demo implementing an agent-to-agent workflow, with a greeting agent server and a client that discovers and invokes the agent.
`Python` `A2A` `Starlette`
