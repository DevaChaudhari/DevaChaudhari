## Featured projects

### [AustraliaJobSeeker AI](https://github.com/DevaChaudhari/AustraliaJobSeeker-AI)
A visa aware job search assistant for international students in Australia. SEEK has no visa filter, so a LangGraph pipeline searches SEEK, reads each full job ad, checks it against the user's visa (500, 485, 482 or PR), ranks jobs on visa fit and resume skill match, and generates tailored resumes and cover letters. Exposed as a FastAPI REST API, an A2A server and an MCP server, with LangSmith tracing, Docker, Kubernetes manifests and Cloud Run deployment.

`Python` `LangGraph` `Playwright` `Groq` `FastAPI` `MCP` `A2A` `LangSmith` `Docker` `Kubernetes` `Cloud Run`

### [ProjectPilot AI (OmniAgent)](https://github.com/DevaChaudhari/ProjectPilot-AI) · [Live app](https://omniagent-ai-autonomous-multi-agent-system-y89sgqgnrycvy64yjpa.streamlit.app/)
An autonomous project building agent. Give it an idea and a tech stack, and a LangGraph workflow plans the work, generates a runnable starter app, packages it as a zip and can push it straight to GitHub. FastAPI backend, Streamlit interface, Docker Compose, Kubernetes and a GitHub Actions workflow publishing images to GHCR.

`LangGraph` `FastAPI` `Streamlit` `PyGithub` `Docker` `Kubernetes` `GitHub Actions`

### [YouTube RAG Chatbot](https://github.com/DevaChaudhari/YouTube-RAG-Chatbot) · [Live app](https://youtube-rag-chatbot-fq8fy6zy9vw2ohypqiztit.streamlit.app/)
Ask questions about any YouTube video in plain English. A four stage RAG pipeline with Google Gemini embeddings and FAISS gives under 500 ms semantic search across transcripts of 100K+ tokens.

`LangChain` `Gemini` `FAISS` `Streamlit` `Docker` `Kubernetes`

### [A2A Protocol Implementation](https://github.com/DevaChaudhari/A2A-Protocol-Implementation)
A minimal, working Agent to Agent (A2A) workflow with the A2A Python SDK: a Greeting Agent server publishes its Agent Card and a client discovers and calls it.

`Python` `A2A` `Starlette` `Uvicorn` `uv`
