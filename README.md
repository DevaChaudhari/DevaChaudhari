### 🚀 Featured Projects

**[AustraliaJobSeeker-AI](https://github.com/DevaChaudhari/AustraliaJobSeeker-AI)** — End-to-End AI Agent Job Platform
Solves a real problem: Seek.com has no visa filter for international students. Built a LangGraph multi-agent pipeline that scrapes live jobs, filters by visa type (500/485/482/PR), ranks by resume match, and auto-generates tailored resumes and cover letters. Custom MCP servers expose job search, visa checks, and resume tailoring as callable tools; A2A servers enable true multi-agent collaboration. Deployed on Google Cloud Run with Docker, Kubernetes manifests, and full CI/CD via Cloud Build. Migrated from Ollama to Groq for cloud-scale inference.
`Python` `LangGraph` `LangSmith` `Groq` `FastAPI` `MCP` `A2A` `Docker` `Kubernetes` `Cloud Run`

**[ProjectPilot-AI](https://github.com/DevaChaudhari/ProjectPilot-AI)** — Autonomous Multi-Agent System
Production-grade agent platform with dedicated planner, executor, and tool-selection agents for dynamic task planning and multi-step LLM reasoning. Integrates 6+ external APIs (GitHub, REST, file systems, web browsing) for fully automated workflows, running on local LLM inference via Ollama to eliminate cloud costs.
`Python` `LangGraph` `LangChain` `FastAPI` `Streamlit` `Ollama`

**[YouTube-RAG-Chatbot](https://github.com/DevaChaudhari/YouTube-RAG-Chatbot)** — RAG Pipeline for Video Content
End-to-end RAG chatbot for querying YouTube video content in natural language. 4-stage pipeline (metadata extraction → transcript loading → FAISS indexing → context-aware generation) achieving sub-second retrieval across 100K+ token transcripts. Dockerized with Kubernetes manifests for production deployment.
`Python` `LangChain` `Gemini` `FAISS` `Streamlit` `Docker` `Kubernetes`

**[A2A-Protocol-Implementation](https://github.com/DevaChaudhari/A2A-Protocol-Implementation)** — Agent-to-Agent Protocol Demo
Minimal Python A2A-SDK demo implementing an agent-to-agent workflow with a greeting agent server, Starlette/uvicorn A2A endpoint, and a client that discovers and invokes the agent.
`Python` `A2A` `Starlette`
